
# IS413 — Mission 07 (Hoopes)

## How to run
1. Download `MovieCollection.sqlite` from:
   https://byu.box.com/s/7r68gh9tz6e22criq36k2shrp47f2pv2
2. Place `MovieCollection.sqlite` in the project root (same folder as Mission06_Hoopes.csproj).
3. Do NOT commit your local `appsettings.json` or the DB file. They are intentionally excluded.
4. Open the project in Rider and run the web app (use the Run ▶ button). If Rider asks to restore NuGet packages, allow it.
